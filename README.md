# Atlas Rápido

Landing page do **Kit de Mapas Mentais para Revisões Rápidas em Medicina** — mapas mentais, resumos autorais e fichas-resumo.

Site estático, sem build — `index.html` é a página inteira (CSS e JS inline). Publicado via GitHub Pages.

## Editar

- Preços, links de checkout e textos: procure os comentários `<!-- EDITE: ... -->` no `index.html`.
- Ativar/desativar entregáveis (mapas clínicos extras, questões, flashcards, bônus): edite o objeto `FEATURE_FLAGS` no final do arquivo, dentro da tag `<script>`.
